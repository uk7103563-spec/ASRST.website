# Urban Carnivora — Marketing Website

Static, responsive marketing website built from the supplied Urban Carnivora screenshots and business details.

## Run
Just open `index.html` in a browser.

For local development:
- VS Code + Live Server, or
- `python -m http.server 5500`
- then open http://localhost:5500

## Important before launch
1. Replace the reference screenshots in `assets/` with original, high-resolution business photos.
2. Confirm phone numbers, address, pricing and service availability with the business.
3. Confirm the Google Maps/WhatsApp links.
4. Add the business's real logo if available.
5. If publishing commercially, review Google Maps/Google Places data-use requirements rather than copying Google listing content directly.
